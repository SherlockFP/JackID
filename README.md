# JackID

First-person PSX-style light-horror casino roguelike + tycoon (Three.js / TypeScript / Vite). Solo or 2–8 friends over P2P.

```bash
npm install
npm run dev      # http://localhost:5180
npm run server   # lobby / signaling / relay (+ serves dist/)
```

**New developer or AI taking over? Start with [`docs/HANDOFF.md`](docs/HANDOFF.md).**
